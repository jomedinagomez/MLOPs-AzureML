# **Two-Day Azure Machine Learning Workshop**

## **Day 1: Azure ML Foundations and Pipelines**

1. Azure Machine Learning introduction slides provided by the instructor.
2. Azure ML Studio tour: workspace, notebooks, compute, data, models, environments, endpoints, jobs, pipelines, and registries.
3. Register and inspect a data asset, environment, and model with the Python SDK v2.
4. Submit and inspect a command job.
5. Create, deploy, and invoke a managed online endpoint.
6. Submit the single-step merge job from a notebook.
7. Submit the integration compare pipeline from a notebook and inspect its child jobs and outputs.
8. Review lineage, reproducibility, immutable versions, managed identities, logs, and Day 2 prerequisites.

## **Day 2: H2O Models and Wells Fargo BYOM Onboarding**

1. Contrast native H2O binaries with portable MOJO artifacts; review OpenJDK 17, manifests, checksums, and golden tests.
2. Create and validate the reference H2O binary-model bundle.
3. Submit the reference offline-scoring pipeline.
4. Package a Wells Fargo-provided native H2O binary or MOJO without changing the local notebook environment; golden data is optional.
5. Register the packaged customer bundle as an immutable custom model.
6. Create and register the customer-specific, version-pinned H2O environment.
7. Generate and submit the Wells Fargo scoring pipeline YAML.
